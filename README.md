# دموی سایت پوشش ساختمان

## اجرا
فایل `index.html` را در مرورگر باز کنید (نیازی به نصب یا اینترنت نیست). فونت وزیرمتن داخل پوشه `fonts` است.

## ساختار صفحات
index.html (خانه)، about، concrete، equipment، lab، delivery، joist، gallery، contact — همه از منوی بالا در دسترس‌اند. هدر/فوتر در همه صفحات یکسان است.

## جایگزینی تصاویر خودتان
عکس‌های شرکت را **با همین نام‌ها** در پوشه `images/` بگذارید (فرمت jpg؛ بهتر است عرض ≤ ۱۹۲۰ و حجم زیر ۳۰۰ کیلوبایت):

| فایل | محل استفاده |
|---|---|
| hero.jpg | تصویر بالای صفحه (افقی، ۱۹۲۰×۱۰۸۰) |
| about.jpg | بخش درباره ما |
| plant.jpg | بچینگ پلنت |
| trucks.jpg | میکسرها |
| pump.jpg | پمپ بتن |
| lab.jpg | آزمایشگاه |
| joist.jpg | تیرچه |
| gallery-1.jpg … gallery-6.jpg | گالری پروژه‌ها |
| logo.svg | لوگو (موقت) |

- لوگوی واقعی: اگر PNG است، فایل را در `images/` بگذارید و در `js/config.js` مقدار `logo` را به `images/logo.png` تغییر دهید.
- در `js/config.js` مقدار `demo` را `false` کنید تا برچسب‌های «تصویر نمونه» حذف شوند.
- شماره تلفن و واتساپ هم در همان فایل `js/config.js` تنظیم می‌شود.

## نکات
- فرم نمایشی است و به هیچ سروری وصل نیست.
- مواردی که با عبارت «[اطلاعات نیازمند تأیید شرکت]» مشخص شده‌اند باید از شرکت گرفته شوند.
